## Projetos Desenvolvidos | Projects Developed  

### 1. **Treinamento de Redes Neurais com Transfer Learning**  
Utilizei técnicas de transferência de aprendizado para aproveitar redes pré-treinadas e resolver problemas complexos, ajustando os modelos para novas tarefas.  

### 1. **Neural Network Training with Transfer Learning**  
I used transfer learning techniques to leverage pre-trained networks and solve complex problems, fine-tuning models for new tasks.  

### 2. **Redução de Dimensionalidade em Imagens para Redes Neurais**  
Implementei métodos para simplificar dados visuais sem perder informações importantes, aumentando a eficiência dos modelos.  

### 2. **Dimensionality Reduction in Images for Neural Networks**  
I implemented methods to simplify visual data without losing important information, increasing model efficiency.  

### 3. **Cálculo de Métricas de Avaliação de Aprendizado**  
Desenvolvi scripts para calcular métricas como precisão, recall e F1-score, garantindo a avaliação precisa do desempenho dos modelos.  

### 3. **Learning Evaluation Metrics Calculation**  
I developed scripts to calculate metrics such as precision, recall, and F1-score, ensuring accurate model performance evaluation.  

### 4. **Criação de Uma Base de Dados e Treinamento da Rede YOLO**  
Criei uma base de dados do zero e treinei a rede YOLO para detectar objetos em imagens, explorando técnicas de visão computacional.  

### 4. **Database Creation and YOLO Network Training**  
I created a database from scratch and trained the YOLO network to detect objects in images, exploring computer vision techniques.  

### 5. **Criando um Sistema de Reconhecimento Facial do Zero**  
Desenvolvi um sistema completo de reconhecimento facial capaz de identificar e verificar rostos em imagens.  

### 5. **Creating a Facial Recognition System from Scratch**  
I developed a complete facial recognition system capable of identifying and verifying faces in images.  

### 6. **Sistema de Recomendação por Imagens Digitais**  
Desenvolvi um sistema de recomendação baseado em características visuais, aplicando aprendizado não supervisionado e técnicas de clustering.  

### 6. **Digital Image Recommendation System**  
I developed a recommendation system based on visual characteristics, applying unsupervised learning and clustering techniques.  

### 7. **Sistema de Assistência Virtual do Zero**  
Construi um assistente virtual que utiliza processamento de linguagem natural e APIs para interagir com usuários de forma inteligente.  

### 7. **Virtual Assistance System from Scratch**  
I built a virtual assistant that uses natural language processing and APIs to interact intelligently with users.
